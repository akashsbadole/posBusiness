## 🧪 Testing Scenarios

Use these accounts to test:
1. **Multi-business support** - Switch between different business types
2. **Role-based access** - Test different permission levels
3. **Industry-specific features** - Test unique features per business type
4. **Order management** - Test different order types (DINE_IN, TAKEAWAY, DELIVERY, etc.)
5. **Staff management** - Test staff creation and role assignment
6. **Business settings** - Test configuration per business type

## 🔄 Switching Between Businesses

To test different businesses:
1. Logout from current account
2. Login with credentials from desired business type
3. The system will automatically load the relevant business configuration
